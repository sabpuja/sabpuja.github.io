# Sab Puja Preview

Lightweight preview/demo surface for work that should not live directly in the production Shopify theme.

## Intended uses
- Design-system component demos
- Static UX concepts
- Internal previews for stakeholder review
- Documentation examples when useful

## Not intended for
- Production ecommerce
- Customer checkout
- Canonical product/content data
- Replacing Shopify theme previews

## Rule
Use this repo only when a standalone preview materially improves review or collaboration. Production storefront implementation belongs in `sabpuja/theme`.
