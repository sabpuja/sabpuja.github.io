Image Optimization Lab

Sabpuja media should be compressed by changing both format and dimensions. The GitHub pipeline generates responsive AVIF and WebP variants without enlarging source images.

Automated workflow

Source JPG / PNG / WebP→Strip metadata→Resize responsibly→AVIF + WebP→Manifest + size report

Source folder

Do not manually pre-compress sources before the pipeline. We want one high-quality master.

Generated folder

The workflow writes optimized derivatives here:

assets/images/optimized/

Generated files use widths of 480, 768, 1200, 1600 and 1920 where the source is large enough.

Shopify rule: when an image is stored as a Shopify image object, final storefront code should still use responsive image_url/image_tag or a <picture> element for art-directed mobile crops. GitHub compression prepares efficient masters; Shopify handles last-mile responsive delivery.
