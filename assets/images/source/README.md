# Source images

Place high-quality master storefront images in this directory.

Supported raster formats: JPG/JPEG, PNG, WebP and AVIF.

The GitHub Action `Optimize storefront images` generates responsive WebP and AVIF derivatives in `assets/images/optimized/` at widths 480, 768, 1200, 1600 and 1920 where the source is large enough. Images are never enlarged.

Do not place customer-private material, credentials or unpublished confidential assets here. This repository is intended to back a preview website.
