# Preview Guidelines

Use this repository for static demos, component previews, and stakeholder-review surfaces that do not belong in the production Shopify theme.

## Good uses
- Design-system component gallery
- Static homepage/product-page concepts
- Before/after comparison demos
- UX prototypes that need a shareable URL

## Avoid
- Duplicating production Shopify content
- Maintaining a second storefront
- Storing canonical product data
- Shipping customer-facing ecommerce functionality here

## Promotion path
A successful preview should be translated into the appropriate source repo:
- design decisions → `sabpuja/design-system`
- copy/content → `sabpuja/content`
- production storefront implementation → `sabpuja/theme`
- requirement/decision → `sabpuja/core`
